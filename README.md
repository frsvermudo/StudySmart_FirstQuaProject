# StudySmart_FirstQuaProject
A proposed Python program that helps students organize their study time based on tasks, deadlines, and difficulty.

## How to Run
The program will be run using Python. Open the Python file in a Python-supported editor or IDE, then run the program.

## Input Needed
The user will enter:
- Available study time
- Task name
- Task difficulty
- Number of days until the deadline

## Sample Output

Study Schedule

1. Mathematics - 1 hour
2. Chemistry - 45 minutes
3. English - 30 minutes

Good luck with your studies!
